# Main pages — V2 notes, sources, and claims to confirm

Eleven `.v2.html` files sit next to their originals in this folder. Nothing in the originals
was changed. Each v2 file opens with a comment listing what changed on that page.

`zoley-pricing-hybrid.html` was not given a v2: it is an older variant of `zoley-pricing.html`
with identical copy, so `zoley-pricing.v2.html` supersedes both.

---

## 1. What changed across every page

- **Voice.** Rewritten in a more authoritative consulting register. Still plain English,
  still "we", still the handwritten tags and warm palette. The main moves: specific claims
  instead of adjectives, a named deliverable at every step, and candor sections that say
  when we'd advise against the service.
- **Primary conversion.** Every primary button now goes to the Quick Start form
  (`/find-your-next-best-business-move`). The Calendly call is the secondary button everywhere.
  The Quick Start page itself was reworked to explain what the visitor receives before it asks
  for anything.
- **The promise.** The site now repeats one offer: *answer a few questions, get a written
  recommendation with a fixed price within two business days, no obligation.* You need to be
  able to keep that promise. If two business days is too tight, search-and-replace
  "two business days" across the v2 files before publishing.
- **Illustrations.** Seventeen inline SVG illustrations in the hero-board style, plus PNG and
  SVG exports in `Assets/v2-illustrations/` (see section 4). Every service page now has an
  illustrated two-column hero. Every case-study block has an illustrated mock instead of a
  grey placeholder.
- **Statistics.** Every external number was replaced with one that can be attributed to a
  named source (section 2). Sources are deliberately not cited on-page, per your call.
- **Content-pending sections** on the web and advertising pages were drafted (the tracking
  and metrics blocks). Edit freely.
